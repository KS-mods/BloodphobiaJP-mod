# Detective Bloodphobia 非公式日本語化MOD

**機械翻訳とChatGPTを使用した、非公式の日本語化パッチです。** 開発元から無料配布・作品紹介記事の掲載・スクリーンショット使用の許可を得ています。

原作の開発・制作：**Gustav & LuB2an**
正規ゲームの購入・詳細：[Detective Bloodphobia — Steamストア](https://store.steampowered.com/app/3856210/Detective_Bloodphobia/)

Windowsの正規Steam製品版向けです。本文・選択肢と対応するUI・画像文字を日本語で表示します。画像は利用者のゲームから読み込み、日本語を重ねて表示します。

**マウスホイール操作の改善MODも同梱しています。** 「日本語化を適用」で一緒に有効になり、別途導入する必要はありません。下ホイールで全文表示／会話送り、上ホイールでログを開き、ログ内では上下にスクロールできます。「アンインストール」で日本語化とホイール操作の変更をまとめて戻します。

## 導入・更新

1. ゲームを終了し、ZIPをすべて展開してください。
2. BloodphobiaJP.exeを開いてください。Steamのゲーム保存先を自動で探します。展開先はデスクトップやダウンロードフォルダーでも構いません。
3. 「日本語化を適用」を押してください。見つからない場合や複数見つかった場合は、Game.exeのあるフォルダーを選んでから押してください。
4. 完了後、「ゲームを起動」またはSteamから通常どおり起動してください。

PythonやCodexのインストールは不要です。パッチはアプリ内に同梱しているため、BloodphobiaJP.exe単体でも導入できます。初回の展開とボタン操作の後は、ゲームを普通に起動するだけです。新版も同じ操作で更新できます。対応する元ファイルのハッシュを照合し、ゲームの更新や他のMODによる違いがある場合は上書きせず停止します。更新時は前のパッチと復旧用バックアップを保存します。

## アンインストール・中断からの復旧

ゲームを終了してBloodphobiaJP.exeを開き、「アンインストール」を押してください。確認画面で続行すると、変更したゲームファイルを導入前の状態へ戻します。セーブは削除・上書きしません。再び「日本語化を適用」を押せば再インストールできます。

MOD適用中に保存したセーブには、実行途中の会話や会話ログが日本語で記録されている場合があります。そのセーブをロードすると、アンインストール後も一部の文章が日本語で表示されることがあります。アンインストールではセーブ内の文章を変換しません。新規開始時の表示で、ゲーム本体が元の言語に戻っていることを確認できます。

「状態を確認」で適用ファイルを照合できます。処理が中断された場合は「中断から復旧」を実行してください。

バックアップと導入記録はゲームフォルダー内の.BloodphobiaJPに保存されます。MOD適用中は、このフォルダーを削除・移動しないでください。開発版を使用していた場合は、そのDetectiveBloodphobia_JP内の既存バックアップを引き継ぎます。

## 操作と翻訳の確認状態

- 下ホイール：表示途中は全文表示、表示済みは会話送り。
- 上ホイール：既存の会話ログを開きます。ログ内では上下ホイールでスクロール、Esc／戻るで閉じます。
- 選択肢・証拠／設問画面・F6パネルではホイールによる会話送りを抑制します。
- F6：対応画像の文字の仮訳を確認できます。
- Ctrl+Shift+F7：本文を含まない問題の位置記録をゲーム内のDetectiveBloodphobia_JP/local/player-reportsに保存します。

翻訳は機械訳をGPTで文脈と照合して推敲した非公式訳です。抽出した本文・選択肢8,264件と補助項目1,316件を見直しています。パッチ制作者自身が一通りプレイし、大きな問題なく作品を楽しめたことを確認しています。全訳文の体系的な人手校閲、未知のUI経路や別の実機PCでの確認は未完了のため、β版として扱っています。一部の解釈と画像文字は保留です。

## 配布物

配布用ZIPには日本語訳、元ファイルの照合ハッシュ、独自の表示コード、導入ツールとそのソース・ライセンスを含みます。ゲーム本体の画像・音声・実行ファイル・元スクリプト、開発用原文カタログ、利用者のセーブやバックアップは含みません。利用には各自が所有する正規ゲームが必要です。

ライセンス表示はLICENSES.txtにまとめています。独自ツールはMIT、内蔵のPython・Tcl/Tk・OpenSSLには各コンポーネントのライセンスが適用されます。配布時にはLICENSES.txtも一緒に含めてください。ツールのライセンスと、開発元から得た無料パッチ配布の許可は別に扱います。ゲーム本体の素材や元スクリプトの配布は、このパッチに含めません。

## 開発者用

ソースはsource/、パッチはpayload/、対象バージョンとSHA-256はversion.json、同梱ファイルのSHA-256はmanifest.jsonにあります。

コマンドからは `BloodphobiaJP.exe apply --game "ゲームフォルダー" --write --report "結果.json"`、`status`、`uninstall --write`、`recover --write` を利用できます。apply／uninstall／recoverは、--writeを省くと確認だけを行います。GUI版のコマンド結果は--reportでJSONファイルに保存してください。

Windowsでの再ビルドは `python -m PyInstaller --onefile --windowed --noupx --paths source --add-data "payload;bundle/payload" --add-data "version.json;bundle" --add-data "LICENSES.txt;bundle/licenses" source/installer_gui.py --name BloodphobiaJP`。Pythonのtkinterが必要です。
